# NOVA CLIENT

A Minecraft Java launcher project built with Tauri 2, React, and TypeScript.

## Status

This repository is an initial scaffold. Minecraft installation, authentication, mod management, in-game HUD integration, and social features are not implemented yet.

## Development

Install dependencies with `npm install`, then run `npm run dev` for the Vite development server. Use `npm run tauri dev` to launch the desktop shell when the Rust toolchain and platform prerequisites are installed.

## Roadmap

- Desktop launcher interface and profile management
- Minecraft version installation and Microsoft authentication
- Fabric/mod loader and modpack management
- Performance mod recommendations and configuration
- PvP HUD and in-game integration
- Friends, chat, and server tools

Features will be marked complete only after implementation and testing.
